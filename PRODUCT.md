# Product

<!-- impeccable:product-schema 1 -->

## Platform

desktop

## Stack

delegated: Qt Quick app already in this folder. Inferred. The user asked for a separate desktop app, not a new web stack.

## Users

Inferred. One person at a night desk, about to send another agent prompt, who needs the remaining Claude, Codex, and Grok allowance before the window resets.

## Product Purpose

Inferred. Show limits, usage, and cost from the same local history as the T3 Code Usage panel. Success means the Claude session and weekly limits are visible without a hidden tab.

## Positioning

Inferred. A single meter for the logins already on this computer. It does not install a proxy, a hub, or a second agent.

## Constraints

- Do not install or configure CLIProxy, CLIProxyAPI, or any hub.
- Do not read or print login tokens.
- Cost is an API estimate, not the subscription bill.
- Follow the Omarchy accent and window radius.
- English only. No Danish catalog.
- Usage comes from the T3 scan cache when that cache is present. If the cache is absent, the app reads local Claude and Codex transcripts.
- Prices come from a downloaded LiteLLM price file. A built-in copy is the offline fallback.

## Assumptions

Every fact above is inferred from the request. No interview tool was available, so the brief stands in for the ask round.
